# BilimCode AI
7–9-сыныпқа арналған қазақша Python оқу платформасының алғашқы демонстрациялық нұсқасы.

## Компьютерде іске қосу
1. Python 3.10+ орнатыңыз.
2. Осы папкада терминал ашыңыз.
3. `pip install -r requirements.txt`
4. `.env.example` файлын `.env` деп көшіріп, `OPENAI_API_KEY` мәнін өз кілтіңізге ауыстырыңыз. Кілтті ешкімге жібермеңіз.
5. `uvicorn main:app --host 0.0.0.0 --port 8000` командасын орындаңыз.
6. Браузерде `http://localhost:8000` ашыңыз.

## Интернетке орналастыру (Render мысалы)
1. Жоба файлдарын өзіңіздің жеке GitHub репозиторийіңізге салыңыз (`.env` файлын салмаңыз).
2. Render-де жаңа Web Service жасап, репозиторийді қосыңыз.
3. Build command: `pip install -r requirements.txt`
4. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Environment variables ішіне `OPENAI_API_KEY` және қажет болса `OPENAI_MODEL` енгізіңіз.
6. Render берген URL арқылы сайтты ашыңыз.

## Маңызды шектеулер
- Бұл бастапқы MVP. Сайт әзірше интернетке жарияланған жоқ; жариялау үшін өз аккаунтыңыз қажет.
- Python коды серверде орындалмайды. Жергілікті синтаксистік тексеру толық емес.
- Ұпайлар тек браузердің localStorage жадында сақталады; шынайы рейтинг немесе оқушы аккаунттары жоқ.
- ЖИ тек API кілті қосылғанда жұмыс істейді және API қызметі ақылы болуы мүмкін.
- Ашық интернетке шығарудан бұрын аутентификация, сұраныс шектеуі және шығын лимиттерін қосыңыз. Оқушылардың жеке деректерін енгізбеңіз.
